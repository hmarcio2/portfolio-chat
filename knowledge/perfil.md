## Projeto DSS: agente de IA com RAG (cliente internacional)

Neste projeto Heriberto trabalhou com agentes de IA em produção. Foi responsável pelo ciclo completo, da prova de conceito à produção em escala. Construiu um agente de IA no padrão ReAct com RAG, orquestração de tools e consumo de APIs externas. Criou uma ferramenta de data analytics que converte planilhas do usuário em Parquet e usa DuckDB para o agente executar SQL sobre os dados enviados. Implementou comparação entre arquivos do usuário e a base de conhecimento interna (RAG). Observabilidade e versionamento com Langfuse e MLflow; deploy em Azure (Blob Storage, Service Bus, Azure Functions, Azure Search) e Alibaba Cloud. Tecnologias: LangChain, MongoDB, Redis, Databricks, FastAPI, Docker, CI/CD.
